# Put this README on GitHub

1. Extract `Forge-Sentinel-README-Kit.zip`.
2. In `Beans-Melon/Forge-Sentinel-Releases`, return to the repository’s **Code** tab. Leave the current README edit without committing its old contents if needed.
3. Choose **Add file → Upload files**.
4. Upload **README.md** and the **assets** folder together at the repository root. Do not upload the outer kit folder or ZIP as the README.
5. Commit with a message such as `Improve Forge Sentinel README and visual guide`.
6. Open the repository homepage. Check that the banner and capability graphic load and both Mermaid diagrams render.

The ZIP contains the README, its artwork and this upload guide. Only `README.md` and `assets` are needed on the repository homepage.

This README documents v0.44 preview. Keep its version, feature descriptions and testing note aligned with future releases. The download links lead to Releases rather than assuming that a specific release has already been published.
